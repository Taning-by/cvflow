## 已确认没问题的部分

- 引擎到界面的事件都经过 Qt 信号转到 GUI 线程，没有发现工作线程直接操作控件。
- Modbus PDU 上限（125/2000/123/1968）、MBAP 事务号校验、CRC、32 位字序（ABCD/CDAB/BADC/DCBA）、MC 3E 帧长度和软元件代码都正确。
- 海康：Free 在 finally 里，帧在 Free 之前已复制；迈德威视：缓冲复制、`ReleaseImageBuffer`、UnInit 都正确；Mono10/12 解包正确。
- DL 预处理快速路径和通用路径结果一致（误差 2e-6）；letterbox 坐标还原、批次切分、共享 session 都没问题。
- 各通信对话框点取消不会改动原规则。
